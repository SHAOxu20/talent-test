# 天赋自测 · Talent Test

趣味天赋自测网页应用：12 道生活化直觉题，3 分钟测出你的核心天赋倾向。

> 纯前端 · 单文件 · 无后端 · 打开即用

## 这是什么

一份基于日常场景的趣味天赋自测工具，帮你快速了解自己的天赋倾向。所有题目贴近生活，不需要思考，凭第一直觉作答即可。

- 目标人群：对自我探索感兴趣的 18–35 岁用户
- 测试时长：约 3 分钟
- 题目数量：12 题，每题 4 个选项（A/B/C/D）
- 作答方式：凭直觉，选最像自己的那个

## 四种天赋维度

| 维度 | 含义 | 典型能力 |
| --- | --- | --- |
| A · 表达型 | 语言、沟通、文字、表演 | 开口即高光，人群中的聚光灯 |
| B · 逻辑型 | 分析、推理、数学、系统化思维 | 拆解问题、找出规律、推演结果 |
| C · 创造型 | 想象力、艺术感知、创新、审美 | 脑洞与灵感，换个角度看世界 |
| D · 行动型 | 执行力、动手、运动、实践操作 | 说干就干，把想法变成现实 |

## 结果类型

- **天生表达者**：表达力突出，社交磁场拉满
- **逻辑大师**：理性大脑，拆解推理满分
- **创意天才**：灵感雷达，脑洞审美超纲
- **行动派王者**：落地机器，执行力爆棚
- **全能型选手（彩蛋）**：四维均衡触发隐藏结果

每种结果包含综合评分（x.x/10）、四维雷达图、详细分析、成长建议、适配方向与一句传播金句，支持保存图片与分享。

## 页面结构

1. **首页**：测试标题、引导文案、开始测试按钮、四种天赋类型预告卡片
2. **答题页**：进度条 + 题号、4 个选项卡片（点击高亮）、上一题/下一题切换、过渡动画，适配手机端
3. **结果页**：综合评分、四维雷达图（渐变填充 + 动画）、维度分数条、详细分析、成长建议、适配方向、保存图片 / 分享按钮

## 如何使用

直接双击打开 `天赋自测.html` 即可在浏览器中运行，无需安装任何依赖。

也可以部署到任意静态托管服务（GitHub Pages、Vercel、Netlify 等）。

## 技术说明

- 单文件 HTML，CSS / JavaScript 全部内联，无构建步骤
- 原生 JavaScript 实现：hash 路由、状态管理、Canvas 雷达图动画
- 保存图片使用 html2canvas（jsDelivr + cdnjs 双 CDN 兜底），离线时自动提示使用系统截图
- 分享优先调用系统分享面板（Web Share），否则复制结果文案到剪贴板
